# Examples

These files are generated by `npm run examples` from the fixtures in `test/fixtures/`.
They contain no real host data, so they can be checked in and reviewed safely.

| File | What it shows |
| --- | --- |
| `table.txt` | Default table for a machine with a Codex auto-start Windows service. |
| `report.json` | Full `--json` report for the same scenario. |
| `report-clean.json` | Full `--json` report for a machine with no target agents. |
| `ci-fail.txt` | `--ci` with an observed persistent daemon (exit 1). |
| `ci-fail-autoupdate.txt` | `--ci` with an explicitly enabled OpenCode auto-update and no daemon (exit 1). |
| `ci-pass.txt` | `--ci` with auto-update explicitly disabled (exit 0). |

Regenerate with:

```bash
node scripts/gen-examples.js
```
